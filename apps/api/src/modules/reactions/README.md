# Módulo `reactions`

> Ainda não implementado. Este arquivo define a fronteira do módulo para orientar a implementação.

Reações a posts e comentários. O objetivo do Ponto não é maximizar curtidas: os tipos de reação devem carregar significado (por exemplo, "bom argumento") para alimentar `feed`.

**Depende de:** `posts`, `comments`, Redis (contadores).
