# Módulo `notifications`

> Ainda não implementado. Este arquivo define a fronteira do módulo para orientar a implementação.

Geração e entrega de notificações (in-app, e-mail, push). Recebe eventos de outros módulos e processa a entrega de forma assíncrona.

**Depende de:** Redis (filas), provedores externos atrás de interfaces próprias.
