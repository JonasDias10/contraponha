# Código de conduta

O Contraponha existe para conversas que valem a pena, e isso começa aqui, entre quem constrói o projeto.

## O que esperamos

- Discordar das ideias, nunca das pessoas. Critique o código e as decisões com argumentos.
- Ser acolhedor com quem está começando e paciente com perguntas.
- Assumir boa-fé e pedir esclarecimento antes de concluir.
- Reconhecer o trabalho dos outros e aceitar crítica construtiva.

## O que não aceitamos

- Assédio, ataques pessoais, insultos e linguagem discriminatória de qualquer tipo.
- Conteúdo sexual ou violento, e atenção indesejada.
- Publicar informações privadas de alguém sem permissão.
- Qualquer conduta que seria inadequada num ambiente profissional.

## Aplicação

Relate comportamentos inadequados às pessoas mantenedoras pelo relato privado do GitHub (aba **Security**, **Report a vulnerability**, indicando no título que é sobre conduta). Os relatos são tratados com sigilo.

As pessoas mantenedoras podem remover comentários, commits e contribuições que violem este código e, conforme a gravidade, advertir, suspender temporariamente ou banir quem o violou.

Este código vale para os espaços do projeto (issues, pull requests, discussões) e para quando alguém representa o projeto publicamente. Ele se inspira no [Contributor Covenant](https://www.contributor-covenant.org/), versão 2.1.
